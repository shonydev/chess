# Chess

## Rayos X — entrenador de ejercicios

**Probar la app:** https://shonydev.github.io/chess/

La PWA está en [`rayos-x-pwa/`](rayos-x-pwa/). Permite practicar el ejercicio disponible, consultar pistas, comprobar la solución y guardar el progreso localmente. Tras habilitar una vez GitHub Pages en **Settings → Pages → Build and deployment → Source: GitHub Actions**, el despliegue se ejecuta automáticamente al actualizar esa carpeta en `main`.
